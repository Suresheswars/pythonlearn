## Troubleshooting

1. Notebook not running:
   Select the correct Python kernel and rerun from the top.
2. API key/authentication issues:
   Verify environment variables are set correctly.
3. Import errors:
   Install missing package and restart kernel.
4. Tool or agent behavior seems wrong:
   Print intermediate steps and validate tool inputs/outputs.
