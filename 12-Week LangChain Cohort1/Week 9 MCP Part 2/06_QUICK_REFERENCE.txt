⚠️  TROUBLESHOOTING QUICK FIXES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"Port already in use" error:
  FIX: Close other PowerShell windows or:
  taskkill /PID <PID> /F

"No module named" error:
  FIX: Run: pip install mcp langchain langchain-openai langchain-community chromadb beautifulsoup4 python-dotenv

"OpenAI API key not found" error:
  FIX: Create .env file with OPENAI_API_KEY=sk-...

"Connection refused" error:
  FIX: Make sure you started all 4 SERVERS before running CLIENT

"LLM Decision: No matching tool" error:
  FIX: Ask more clearly (e.g., "Learn about X from URL" or "What is X?")

  netstat -ano | findstr :8000

  netstat -ano | findstr :8000 → note PID
  taskkill /PID 1234 /F (replace 1234 with actual PID)
