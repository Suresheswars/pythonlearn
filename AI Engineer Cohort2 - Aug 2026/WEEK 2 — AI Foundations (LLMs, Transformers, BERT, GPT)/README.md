## Learning Outcomes

By the end of this week, you should be able to:

1. Explain what a language model predicts.
2. Describe tokens, tokenization, and vocabulary.
3. Work with embeddings and cosine similarity.
4. Understand transformer and attention basics.
5. Compare BERT and GPT at a high level.
6. Identify common LLM limitations.

## How To Use The Notebook

The notebook is designed with progressive support:

1. First half of code cells has easy hints.
2. Second half has medium hints.
3. Every code cell has a TODO section.
4. Every code cell has a mini challenge (optional but recommended).

Recommended approach:

1. Read the markdown explanation.
2. Attempt the TODO section without jumping to clues first.
3. Use hints only when stuck.
4. Run and validate output at each step.
5. Try mini challenges after the core task.

## Suggested Time Plan

1. Concepts and reading: 30 to 40 minutes
2. Core TODO coding tasks: 60 to 90 minutes
3. Mini challenges and review: 20 to 30 minutes

1. Notebook does not run:
   Select the correct Python kernel and rerun cells.
2. Import error:
   Install missing package, then restart kernel.
3. Unexpected output:
   Clear output and rerun cells in order from top to bottom.
