# Capstone Project Options

Students should select **one** of the following capstone options and complete it end-to-end.

## Option 1: Smart Resume Screener 2.0
Path: `1_Smart_Resume_Screener_2_0/`
- PDF resume ingestion
- Skill extraction
- Skill-gap analysis against target role
- Structured JSON output

## Option 2: Chat With Your Knowledge Base (RAG App)
Path: `2_Chat_With_Your_Knowledge_Base_RAG_App/`
- PDF ingestion
- Embeddings + FAISS indexing
- Retrieval + LLM response generation

## Option 3: Multi-Agent Orchestrator with MCP
Path: `3_Multi_Agent_Orchestrator_with_MCP/`
- LangGraph supervisor-based orchestration
- Specialist agents (e.g., Math + RAG)
- External MCP microservice/tool integrations

## Selection Guidance
Choose based on your interest and comfort level:
- Option 1: Strong for structured extraction and scoring logic
- Option 2: Strong for document Q&A and RAG fundamentals
- Option 3: Strong for orchestration, routing, and tool integrations

## Submission Expectation
- Build a working MVP for your selected option
- Keep architecture modular and readable
- Demonstrate output with one real sample input
